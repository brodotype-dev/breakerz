# Persona Reviews

Longitudinal log of multi-persona critical reviews of BreakIQ. Each session throws a panel of AI agents — each holding a fixed persona — at a feature or the product as a whole, with a deliberately critical lens. Kept over time so we can see how the critiques evolve, which concerns recur, and how the agents themselves behave run-to-run.

**Standing panel** (definitions in project memory → `personas_critique_panel`):
- **The Breaker** — runs live breaks, prices slots, makes money on margin.
- **The Novice Consumer** — new buyer, FOMO-driven, jargon-allergic, small budget.
- **The Whale Consumer** — high-spend across many breaks, sophisticated, wants edge at scale.
- **The Product Manager** — rigor on the right problem, validation loops, value vs. infra.
- **The Investor** — defensibility, market, unit economics, feature-vs-company.

**Convention:** one file per session, `YYYY-MM-DD-<topic>.md`. Each file: what was reviewed, the panel, a synthesis (convergent findings first), and each persona's critique. Findings worth acting on get promoted to [docs/BACKLOG.md](../BACKLOG.md).
